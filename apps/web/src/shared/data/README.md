# COC7 职业空位数据

`coc7-occupation-slots.json` 由用户提供的 `COC7空白卡 (1).xlsx` 中的「本职技能」矩阵整理生成，
用于替代原先从 `skillsText / skillNames` 正则猜测的临时逻辑。

## 结构

- key：COC7 平台职业 code（1~230）。
- `fixed`：固定本职技能，数组项为 `{ skillId, label }`。
- `slots`：可选空位数组：
  - `kind`：`CHOICE`（☆ / ⊙ 二选一）、`SOCIAL`（☯）、`MULTI`（※）、`FREE`（任意特长）。
  - `symbol`：`☆` / `⊙` / `☯` / `※` / `ANY`。
  - `pick`：需要选择的数量。
  - `candidates`：候选技能；`FREE` 由运行时填充为“除克苏鲁神话外的全部技能”。

## Excel 列对应

- 第 1 行：职业 code。
- 第 2 行：职业名。
- 第 3 / 4 / 5 / 6 / 7 行：`☆` / `⊙` / `☯` / `※` / `任意特长` 数量。
- 第 8 行起为技能行：
  - `★`：固定本职。
  - `☆` / `⊙` / `☯` / `※`：对应空位的候选；带前/后缀文字时表示特殊化。
  - 普通文字：固定本职的特殊化（如“技艺① = 制图”）。

## 已知映射限制

- 技能行里的 `Ω` 现代标记被忽略；年代仍由房间 / 职业 `era` 控制。
- 多个外语 / 技艺 / 科学特殊化目前映射到平台现有技能 id；同名 id 会去重，
  尚未支持 `skillId#specialty` 形式的动态技能条目。
- 职业 1「魔术师」在 Excel 矩阵中没有独立列（矩阵的 code 1 是自定义职业），
  由职业文本手工构造。
